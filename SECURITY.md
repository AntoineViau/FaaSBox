# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in FaaSBox, please report it by [opening a GitHub issue](../../issues/new).

Include as much detail as possible:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Scope

FaaSBox is designed as a **personal, single-user** platform. It is not intended to be exposed to untrusted users. Security reports should be evaluated in this context.
